# Connected cube studies

Preview: <http://127.0.0.1:8147/animations/connected/>

Twenty-five subtle responses to the same pearl and closed rear orbit. Each
study owns its effect setup in `study-NN.js`; `motions.js` owns the shared
cube geometry, rear trail, pearl position, and proximity calculation. Effects
receive the pearl position relative to each cube, its direction, and a smooth
280-unit proximity envelope. There are no independent timers or random events.
At zero influence every cube returns to its original appearance. Drawing is
a pure function of the scrub position, including reverse playback and replay.

The gallery preserves pause, scrubbing, favorites, reduced-motion opt-in,
three-second launch previews, and direct `?concept=NN` links. Production is
unchanged. The original animation gallery and trail review remain available.
