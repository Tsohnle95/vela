# Vela release directions

Reference #1 is a standalone OpenBot-inspired release page for Vela: a dark
canvas, mint beam, floating navigation, a full-width workspace preview, an
asymmetric feature grid, a metal `$0`, a four-step workflow, FAQs, platform
downloads, and a honeycomb closing section. Its content is specific to Vela's
desktop IDE, editor, OpenCode sessions, terminal, and live diffs. Three further
takes extend it: Aurora (a cool split hero), Paper (a light editorial
treatment), and Studio (a monochrome tool-like treatment). Reference #2 and the
[thirty further iterations with 24 palettes](iterations/index.html) retain
their corrected Cloudroom-scale typography and screenshot treatments.

Open [the collection](index.html) directly from disk. Twenty-three standalone
compositions share Vela’s real screenshot, current folded mint mark, and
factual product content. No server, build, remote fonts, or external assets
are required.

The visual references are [Cloudroom](https://www.cloudroom.dev/) for the
original collection and [OpenBot](https://openbot.run/) for reference #1 and
its Aurora, Paper and Studio takes, both reviewed live. Reference #1 adapts
OpenBot's dark canvas, centered hero, light beam, bento feature grid, metal
pricing, stacked workflow cards, FAQ, platform downloads, and honeycomb closing
section. The takes keep the same Vela content under different visual
treatments. The other compositions retain the Cloudroom-scale typography and
screenshot treatments. Both references are adapted to Vela's own identity.
Cloudroom's and OpenBot's illustrations, logos, source, and copy are not
included. Their hosting, sandbox, pricing, model-support, agent-team, and usage
claims are not claims about Vela.

Use the bottom selector or Left/Right keys outside interactive controls.
**All designs** opens the thumbnail directory. Escape closes it. The × hides
the review controls; **Designs** restores them. Add `?design=1&clean=1` to
start with collapsed controls. Version 14 has a keyboard-accessible native
radio selector for its editor, agent, and changes explanations. Browser
Back/Forward restores the selected design.

The product pages are presented as real releases. Do not add decorative
eyebrows, specimen IDs, marginal notes, screenshot labels, mock telemetry,
fake metrics, design rationale, or commentary. Keep meaningful headings,
useful product descriptions, real imagery, and functional actions. Design
names and navigation belong in the separate collection controls only.

The collection includes Vela IDE; Aurora; Paper; Studio; Everything in view;
Close to the code; A place to build; One working space; The big picture; Folded
space; Code, together; The shared workspace; In plain view; In orbit; The
wordmark; Good company; The working view; A new angle; After hours; Still
point; First look; Green room; and On your desktop.

Run `node design/vela-product/cloudroom/verify.mjs` from the repository root
under Node 22.23.2. The isolated Electron check renders all 23 layouts at five
widths, checks interactions, and verifies metadata removal across the prior
55 designs at desktop and phone widths. Output goes into a fresh temporary
directory. It never opens the installed app profile or contacts OpenCode.
See [QA.md](QA.md) for the verified scope.
